# YSP Practice Pack Template

_Last updated: 2026-06-30_

## Purpose

This document defines the future paid Full Practice Pack structure.

Practice Packs should be created after public preview lesson structure and source-data workflow are stable.

## Product Relationship

| Product | Purpose | Price Strategy |
|---|---|---|
| Free Preview Lesson | Trust and SEO / social proof | Free |
| Full Practice Pack | Paid low-management product | Low to mid price |
| Guided Trial Lesson | Convert students to 1-on-1 | Booking CTA |
| Course Bundle | Multi-lesson product | Future package |

## Full Practice Pack Sections

A complete pack should include:

```text
1. Lesson overview
2. Core vocabulary review
3. Extended vocabulary reference
4. Useful phrase substitution practice
5. Pronunciation practice
6. Full model dialogues
7. Now You Try dialogue variations
8. Speaking questions
9. Culture discussion prompts
10. Answer key
11. Homework version
12. Teacher notes version if needed
```

## Public vs Paid Boundary

| Section | Free Preview | Full Practice Pack |
|---|---:|---:|
| Overview | Yes | Yes |
| Core vocab | Preview / selected | Full exercises |
| Extended vocab | Reference | Full review |
| Phrases | Yes | Substitution drills |
| Pronunciation | Yes | Extra drills |
| Dialogues | Preview | Full practice set |
| Speaking | Preview | Full worksheet |
| Culture | Yes | Extra questions |
| Answer key | No | Yes |
| Printable PDF | No | Yes |
| Homework | No | Yes |

## Format Options

Recommended output formats:

```text
PDF practice pack
Canva template
Google Docs / Notion student version
optional printable worksheet
```
